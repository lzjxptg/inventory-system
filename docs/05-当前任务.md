# 当前任务边界

> 本轮只允许改动以下范围，超出范围需先确认。

## 一、本轮范围

**当前阶段：基础档案模块**

包含：
- 建表脚本（迁移）：`categories`、`units`、`products`、`suppliers`、`customers`、`warehouses`
- ORM 模型（SQLAlchemy）
- Pydantic Schema（与表字段一一对应）
- CRUD 数据访问层
- API 路由（RESTful）
- 统一响应与异常处理

## 二、本轮不允许

- 前端页面
- 采购、销售、库存、财务模块
- 退货、报表、微信对接、Excel 导入导出
- 用户登录 / JWT 鉴权接口（表可留，接口不做）
- 操作日志接口（表可留，接口不做）

## 三、完成标准

- [ ] 建表脚本可在 MySQL 8.0 执行，无语法错误
- [ ] ORM 模型字段与 `01-数据库设计.md` 完全一致
- [ ] Pydantic 模型字段与表字段一一对应，含类型与校验
- [ ] 每个 CRUD 接口有参数校验（必填、长度、数值范围）
- [ ] 事务边界在 Service 层声明清楚（基础档案 CRUD 单表操作可隐式事务）
- [ ] 逻辑删除接口不物理删除，只更新 `is_deleted=1`
- [ ] 查询接口默认过滤 `is_deleted=0`
- [ ] 人工 review 通过才进入下一模块
