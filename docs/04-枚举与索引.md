# 枚举字典与关键索引

## 一、枚举字典

> 所有状态、类型集中定义。模型实现时引用此处，禁止硬编码魔数。

### 用户状态 `users.status`
| 值 | 含义 |
|----|------|
| 0 | 禁用 |
| 1 | 启用 |

### 商品状态 `products.status`
| 值 | 含义 |
|----|------|
| 0 | 下架 |
| 1 | 上架 |

### 删除状态 `*.is_deleted`
| 值 | 含义 |
|----|------|
| 0 | 正常 |
| 1 | 已删除 |

### 采购订单状态 `purchase_orders.status`
| 值 | 含义 |
|----|------|
| 0 | 待入库 |
| 1 | 部分入库 |
| 2 | 已完成 |
| 3 | 已取消 |

### 采购入库单状态 `purchase_ins.status`
| 值 | 含义 |
|----|------|
| 0 | 草稿 |
| 1 | 已确认 |

### 销售订单状态 `sales_orders.status`
| 值 | 含义 |
|----|------|
| 0 | 待出库 |
| 1 | 部分出库 |
| 2 | 已完成 |
| 3 | 已取消 |

### 销售出库单状态 `sales_outs.status`
| 值 | 含义 |
|----|------|
| 0 | 草稿 |
| 1 | 已确认 |

### 库存流水方向 `inventory_logs.direction`
| 值 | 含义 |
|----|------|
| in | 入库（库存增加） |
| out | 出库（库存减少） |
| adjust | 盘点调整 |
| lock | 库存冻结（**预留，本期不使用**） |

### 库存流水业务类型 `inventory_logs.biz_type`
| 值 | 含义 |
|----|------|
| purchase_in | 采购入库 |
| sale_out | 销售出库 |
| check_adjust | 盘点调整 |
| initial | 期初库存 |

### 收付款类型 `payments.type`
| 值 | 含义 |
|----|------|
| 1 | 收款（销售） |
| 2 | 付款（采购） |

### 支付状态 `payments.status`
| 值 | 含义 |
|----|------|
| 0 | 未付 |
| 1 | 部分付 |
| 2 | 已结 |

### 支付方式 `payments.pay_method`
`[待确认]` 是否固定枚举。默认自由文本（现金/转账/微信/支付宝）。

## 二、关键索引清单

| 表 | 索引字段 | 类型 | 说明 |
|----|----------|------|------|
| users | username | UNIQUE | 登录账号唯一 |
| roles | name | UNIQUE | 角色名唯一 |
| permissions | code | UNIQUE | 权限码唯一 |
| categories | parent_id | 普通 | 树形查询 |
| units | name | UNIQUE | 单位名唯一 |
| products | sku | UNIQUE | 商品编码唯一 |
| products | name, category_id | 普通 | 名称+分类检索 |
| products | category_id | 普通 | 按分类筛选 |
| suppliers | code | UNIQUE | 供应商编码唯一 |
| customers | code | UNIQUE | 客户编码唯一 |
| warehouses | code | UNIQUE | 仓库编码唯一 |
| purchase_orders | order_no | UNIQUE | 单号唯一 |
| purchase_orders | status, created_at | 普通 | 状态+时间筛选 |
| purchase_orders | supplier_id | 普通 | 按供应商筛选 |
| purchase_order_items | order_id | 普通 | 按订单查明细 |
| purchase_ins | in_no | UNIQUE | 入库单号唯一 |
| purchase_ins | order_id | 普通 | 按订单查入库 |
| purchase_in_items | in_id | 普通 | 按入库单查明细 |
| sales_orders | order_no | UNIQUE | 单号唯一 |
| sales_orders | status, created_at | 普通 | 状态+时间筛选 |
| sales_orders | customer_id | 普通 | 按客户筛选 |
| sales_order_items | order_id | 普通 | 按订单查明细 |
| sales_outs | out_no | UNIQUE | 出库单号唯一 |
| sales_outs | order_id | 普通 | 按订单查出库 |
| sales_out_items | out_id | 普通 | 按出库单查明细 |
| inventory | product_id, warehouse_id | UNIQUE | 商品-仓库唯一 |
| inventory_logs | biz_no, created_at | 普通 | 按单号+时间查流水 |
| inventory_logs | product_id, warehouse_id, created_at | 普通 | 商品-仓库流水追溯 |
| payments | pay_no | UNIQUE | 收付款单号唯一 |
| operation_logs | user_id, created_at | 普通 | 按操作人查日志 |
| operation_logs | biz_no | 普通 | 按单据号查日志 |
