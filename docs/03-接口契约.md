# 接口契约

> 只写：路径、方法、request 字段、response data 字段、可能错误码。  
> 统一响应结构见 `00-SDD总览.md` 第 5 节。

---

## 一、认证

### POST /api/auth/login
- **request**：`{ username: str, password: str }`
- **response.data**：`{ access_token: str, token_type: "bearer", user: { id, username, real_name, roles: [] } }`
- **错误码**：40101 用户名或密码错误

### GET /api/auth/me
- **request**：Header `Authorization: Bearer <token>`
- **response.data**：`{ id, username, real_name, roles: [], permissions: [] }`
- **错误码**：40102 token 无效 / 过期

## 二、基础档案

### 分类

#### GET /api/categories
- **request**：无
- **response.data**：`[{ id, name, parent_id, sort, children: [] }]`（树形）

#### POST /api/categories
- **request**：`{ name: str(≤100,必填), parent_id: int(可选), sort: int(默认0) }`
- **response.data**：分类对象
- **错误码**：40001 参数校验失败；40901 分类名重复

#### PUT /api/categories/{id}
- **request**：同 POST（部分更新）
- **response.data**：分类对象
- **错误码**：40001；40401 分类不存在

#### DELETE /api/categories/{id}
- **request**：无
- **response.data**：`null`
- **错误码**：40902 存在子分类或商品引用，不可删除

### 单位

#### GET /api/units
- **response.data**：`[{ id, name, code, sort }]`

#### POST /api/units
- **request**：`{ name: str(≤20,必填), code: str(可选), sort: int(默认0) }`
- **response.data**：单位对象
- **错误码**：40901 单位名重复

#### PUT /api/units/{id}
- **response.data**：单位对象

#### DELETE /api/units/{id}
- **错误码**：40902 存在商品引用，不可删除

### 商品

#### GET /api/products
- **request query**：`page(默认1), page_size(默认20,上限100), keyword, category_id, status`
- **response.data**：`{ total, page, page_size, list: [{ id, sku, name, category_id, category_name, unit_id, unit_name, spec, purchase_price, sale_price, min_stock, status }] }`

#### GET /api/products/{id}
- **response.data**：商品对象（含分类名、单位名）
- **错误码**：40401 商品不存在

#### POST /api/products
- **request**：
  ```json
  {
    "sku": "str(≤50,必填,唯一)",
    "name": "str(≤200,必填)",
    "category_id": "int(可选)",
    "unit_id": "int(必填)",
    "spec": "str(≤200,可选)",
    "purchase_price": "decimal(≥0,必填)",
    "sale_price": "decimal(≥0,必填)",
    "min_stock": "decimal(≥0,默认0)",
    "status": "int(0/1,默认1)"
  }
  ```
- **response.data**：商品对象
- **错误码**：40001；40901 SKU 重复；40401 单位/分类不存在

#### PUT /api/products/{id}
- **request**：同 POST（部分更新）
- **response.data**：商品对象

#### DELETE /api/products/{id}
- **response.data**：`null`
- **错误码**：40902 存在采购/销售/库存引用，不可删除（或逻辑删除，[待确认]）

### 供应商

#### GET /api/suppliers
- **query**：`page, page_size, keyword`
- **response.data**：`{ total, page, page_size, list: [{ id, code, name, contact, phone, address }] }`

#### POST /api/suppliers
- **request**：`{ code: str(≤50,必填,唯一), name: str(≤200,必填), contact, phone, address }`
- **错误码**：40901 编码重复

#### PUT /api/suppliers/{id} / DELETE /api/suppliers/{id}
- 同通用模式

### 客户

#### GET /api/customers
- **query**：`page, page_size, keyword`
- **response.data**：分页列表

#### POST /api/customers
- **request**：`{ code, name, contact, phone, address }`
- **错误码**：40901 编码重复

### 仓库

#### GET /api/warehouses
- **response.data**：`[{ id, code, name, manager }]`

#### POST /api/warehouses
- **request**：`{ code, name, manager }`
- **错误码**：40901 编码重复

## 三、采购

### POST /api/purchase/orders
- **request**：
  ```json
  {
    "supplier_id": "int(必填)",
    "warehouse_id": "int(必填)",
    "items": [{ "product_id": "int", "quantity": "decimal>0", "price": "decimal≥0" }],
    "remark": "str(可选)"
  }
  ```
- **response.data**：`{ id, order_no, total_amount, status, created_at }`
- **错误码**：40001；40401 供应商/仓库/商品不存在

### POST /api/purchase/ins/{id}/confirm
- **request**：无
- **response.data**：`{ in_no }`
- **错误码**：40901 入库数量超限；40902 单据状态错误；40001 商品不存在

---

## 四、销售

### POST /api/sales/orders
- **request**：同采购订单，字段为 `customer_id`
- **response.data**：`{ id, order_no, total_amount, status }`
- **错误码**：40001；40401；40903 库存不足（提示，[待确认] 是否阻断）

### POST /api/sales/outs/{id}/confirm
- **response.data**：`{ out_no }`
- **错误码**：40903 库存不足；40904 出库数量超限；40905 单据状态错误

---

## 五、库存

### GET /api/inventory
- **query**：`page, page_size, product_id, warehouse_id, keyword`
- **response.data**：`{ total, list: [{ product_id, product_name, warehouse_id, warehouse_name, quantity, min_stock }] }`

### GET /api/inventory/logs
- **query**：`product_id, warehouse_id, biz_type, start_date, end_date, page, page_size`
- **response.data**：`{ total, list: [{ product_name, warehouse_name, change_qty, before_qty, after_qty, direction, biz_type, biz_no, operator_name, created_at }] }`

### POST /api/inventory/check
- **request**：`{ warehouse_id, items: [{ product_id, actual_qty }] }`
- **response.data**：`{ adjusted_count }`
- **错误码**：40002 实盘数量 < 0
