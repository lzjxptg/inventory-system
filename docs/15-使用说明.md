## 1. 初次使用：初始化顺序（必读）

系统各模块之间存在数据依赖，**请严格按以下顺序初始化基础数据**，否则创建订单时会找不到可选的商品/仓库/客户等。

```
① 单位管理  ──┐
              ├──→ ③ 商品管理 ──┐
② 分类管理  ──┘                  │
                                 ├──→ ⑥ 采购订单（入库）→ 库存增加
④ 仓库管理  ─────────────────────┤
                                 ├──→ ⑦ 销售订单（出库）→ 库存减少
⑤ 供应商管理 ────────────────────┘
⑤ 客户管理 ──────────────────────┘
```

### 步骤详解

#### ① 单位管理

**入口**：库存管理 → 单位管理

- 录入商品的计量单位，如「个」「箱」「公斤」「瓶」。
- 单位名称在系统内唯一（逻辑删除后可重名）。

#### ② 分类管理

**入口**：库存管理 → 分类管理

- 录入商品分类，如「食品」「日用品」「电子产品」。
- 分类为选填项，商品可以不挂分类。

#### ③ 仓库管理

**入口**：库存管理 → 仓库管理

- 录入仓库，如「主仓库」「次品仓」。
- 采购入库、销售出库、库存操作都必须指定仓库。

#### ④ 商品管理

**入口**：库存管理 → 商品管理

- 必填：商品编码（SKU）、商品名称、单位。
- 选填：分类、规格、成本价、销售价、预警阈值、状态。
- 商品创建后**库存为 0**，需通过采购入库或库存操作增加库存。

#### ⑤ 供应商 / 客户管理

**入口**：
- 采购管理 → 供应商管理
- 销售管理 → 客户管理

- 供应商用于采购订单，客户用于销售订单。
- 客户可关联多个「门店」（连锁客户），详见第 5 节。

#### ⑥ 采购入库（让库存增加）

**入口**：采购管理 → 新建采购

1. 选择供应商、仓库。
2. 添加商品明细（商品、数量、单价）。
3. 保存采购订单（状态：待入库）。
4. 在采购订单列表点击「入库确认」，填写实际入库数量并确认。
5. 确认后：库存数量增加，库存流水写入 `inventory_logs`。

#### ⑦ 销售出库（让库存减少）

**入口**：销售管理 → 新建销售

1. 选择客户（可选门店）、仓库。
2. 添加商品明细。
3. 保存销售订单（状态：待出库）。
4. 在销售订单列表点击「出库确认」，填写实际出库数量并确认。
5. 确认后：库存数量减少，库存流水写入。
6. 若库存不足，出库确认会被拦截并提示。

## 2. 各模块操作说明

### 2.1 仪表盘

- 展示低库存预警数、本月采购额、本月销售额、库存流水数。
- 采购/销售金额趋势图（按供应商 / 客户）。

### 2.2 库存管理

| 子模块 | 功能 |
|--------|------|
| 库存列表 | 按商品+仓库查看当前库存数量 |
| 库存流水 | 所有出入库记录（direction: in/out/adjust） |
| 库存操作 | 直接调整库存（盘点、报损、报溢），生成 adjust 流水 |
| 商品管理 | 商品 CRUD |
| 分类管理 | 分类 CRUD |
| 单位管理 | 单位 CRUD |
| 仓库管理 | 仓库 CRUD |

### 2.3 采购管理

| 子模块 | 功能 |
|--------|------|
| 采购订单 | 订单列表、入库确认、编辑、删除 |
| 新建采购 | 创建采购订单 |
| 采购退货 | 采购退货单 CRUD + 确认出库 |
| 供应商管理 | 供应商 CRUD |

**采购订单状态**：待入库(0) → 部分入库(1) → 已完成(2)

### 2.4 销售管理

| 子模块 | 功能 |
|--------|------|
| 销售订单 | 订单列表、出库确认、编辑、删除 |
| 新建销售 | 创建销售订单（可选门店） |
| 销售退货 | 销售退货单 CRUD + 确认入库 |
| 客户管理 | 客户 CRUD + 门店管理 |

**销售订单状态**：待出库(0) → 部分出库(1) → 已完成(2)

### 2.5 报表统计

| 子模块 | 功能 |
|--------|------|
| 流水汇总 | 库存流水查询（按商品/仓库/时间/方向） |
| 低库存预警 | 库存低于预警阈值的商品列表 |
| 采购统计 | 采购金额汇总（按供应商/时间） |
| 销售统计 | 销售金额汇总（按客户/时间） |

### 2.6 系统设置（仅 admin）

| 子模块 | 功能 |
|--------|------|
| 角色管理 | 角色 CRUD + 分配权限（权限树勾选） |
| 用户角色 | 用户列表、新建用户（含密码）、修改用户角色 |

## 3. 客户门店管理（连锁客户）

对于一个客户有多个收货门店的场景，可在客户管理中维护门店列表。

### 操作步骤

1. **销售管理 → 客户管理**
2. 在客户列表行点击「**门店**」按钮，打开门店管理弹窗。
3. 点击「**+ 新增门店**」，填写：
   - 门店名称（必填，同一客户下不重复）
   - 联系人、电话、收货地址
   - 是否默认门店（一个客户只能有一个默认门店）
4. 门店可编辑、删除（逻辑删除）、设为默认。

### 在销售订单中使用门店

- 新建销售订单时，选择客户后，「门店」下拉会自动加载该客户的门店列表。
- 门店**可选**，不选则 `shop_id = null`。
- 选择门店后，收货地址会自动带出（可手动修改）。

## 4. 权限说明

系统预置两个角色：

| 角色 | 权限 |
|------|------|
| admin（超级管理员） | 全部权限，可见「系统设置」菜单 |
| operator（操作员） | 查看与创建数据，无删除与配置权限 |

### 新建用户

**入口**：系统设置 → 用户角色 → 「新建用户」

- 填写：用户名、密码（≥6 位）、确认密码、角色（可选，默认 operator）。
- 创建后用户可直接用账号密码登录。

### 分配权限

**入口**：系统设置 → 角色管理 → 行内「分配权限」

- 按模块勾选权限（settings / purchase / sales / inventory / reports）。
- 保存后该角色下的用户重新登录即生效。

## 6. 常见问题

### Q1：创建采购/销售订单时，商品下拉为空？
A：请先在「商品管理」中创建商品（需先创建「单位」）。

### Q2：创建订单时仓库下拉为空？
A：请先在「仓库管理」中创建仓库。

### Q3：销售出库提示库存不足？
A：先通过「采购入库」或「库存操作」补充库存。系统默认不允许负库存。

### Q4：新建用户登录失败？
A：确认密码 ≥ 6 位；若角色被删除，请重新分配角色。

### Q5：浏览器页面空白或报错 `ERR_ABORTED`？
A：镜像重建后浏览器缓存了旧资源，按 `Ctrl + Shift + R` 硬刷新即可。

### Q6：admin 登录提示「用户名或密码错误」？
A：干净重建数据库后 admin 用户不存在，需先调用注册接口创建：
```bash
curl -X POST http://localhost:8002/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123456"}'
```
然后重新执行 `docker compose exec backend python scripts/seed_roles.py` 绑定 admin 角色。

## 7. Docker 运维命令

```bash
# 启动 / 停止
docker compose -p inventory up -d
docker compose -p inventory stop

# 查看日志
docker compose -p inventory logs -f backend
docker compose -p inventory logs -f frontend

# 进入后端容器
docker compose -p inventory exec backend bash

# 跑测试
docker compose -p inventory exec backend python -m pytest tests/ -q

# 干净重建（清空数据库）
docker compose -p inventory down -v
docker compose -p inventory up -d --build
```

默认端口：前端 3000、后端 8002、MySQL 3307、Redis 6379。
