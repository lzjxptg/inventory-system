# 数据库设计

> 所有金额 `DECIMAL(12,2)`，数量 `DECIMAL(12,3)`，时间 `DATETIME`（服务器本地时间）。  
> 主键统一 `id BIGINT AUTO_INCREMENT`。逻辑删除 `is_deleted TINYINT DEFAULT 0`。  
> 外键命名 `fk_<子表>_<父表>_<字段>`，级联规则默认 `ON DELETE RESTRICT ON UPDATE CASCADE`。
